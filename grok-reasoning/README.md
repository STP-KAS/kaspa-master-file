# Grok reasoning

Notes from measured work, kept so a later task can reuse the method.

This folder is not the Now board. It is not a product, and it is not a claim that the note is true. A later pass should read the note, then check the live source again before it repeats a number.

## Rules

- One note per job, dated, with the sources it actually opened.
- Say what was measured, what was not, and what would make the note wrong.
- No wallet addresses, IPs, txids, seeds, real names, or machine paths.
- New notes land on a `build/grok-reasoning-YYYY-MM-DD` branch. They do not go straight to main. No pull request unless stp asks.
- Public Kaspa notes stay experimental. One useful line is enough.
