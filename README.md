# Kaspa master file

### What

Kaspa is a proof-of-work cryptocurrency: miners secure it by spending computing power. It had a fair launch in November 2021, with no premine, so no coins were set aside before public mining began. Instead of a single chain of blocks it keeps a blockDAG: blocks found at the same time all stay in the record, and a rule called GHOSTDAG puts them in order. The Crescendo upgrade brought mainnet to about 10 blocks a second. The Toccata upgrade turned on covenants on the base layer (L1) at DAA score 474165565. A covenant is a rule that a coin carries about how it may be spent next. The DAA score is a counter that rises with every block. SilverScript v1.0.0 is the tagged compiler for writing covenants.

This file is a public pin list for Kaspa and the work around it: the node software, the KIPs (Kaspa Improvement Proposals), covenant conventions, research code, workshop threads, and proposals that are still open. Each claim names the commit or the file it rests on, so anyone can open it and check.

### Why

A release, an open pull request, and a demo are often presented as the same thing. This file gives each one its own row, so every claim can be checked against its source. Grok writes the rows and reads them again, with the automations and a sweep of the sources. The repository account is [STP-KAS](https://github.com/STP-KAS). Kaspa core maintains the node and the KIPs.

The file follows four rules:

- A merged KIP with the status Active is the rule.
- An open pull request is a proposal until it is merged.
- DAGKnight (KIP-2, a consensus proposal) is still a proposal.
- About 100 blocks a second is a later target, not something live.

### How

Each day the automations sweep every source the file names and check each row against it again. The sources are GitHub, X, and public websites. Every pass leaves a receipt in [`SNAPSHOT-HISTORY.md`](SNAPSHOT-HISTORY.md), even when nothing changed. The **Now** board below is the current state, and [`master.json`](master.json) holds the same board as data.

The repository opened on 5 September 2026 as a map of public GitHub repositories, KIPs, and channels. The snapshot log began on 18 September. On 21 September the **Now** board became the current state, and the older sections below it became receipts.

This is an experiment, and whether it is useful is open to debate. A row can lag behind what it watches.
